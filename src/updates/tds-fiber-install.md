TDS Fiber installation is currently underway in our neighborhood.

## TDS Fiber Install information.
Similar to the Fatbeam fiber installation, another provider named TDS has
approval from ACHD to install infrastructure via the utility easement.
After the installation, they are required to perform cleanup and restoration
of any damage including:
- Fill and level any holes
- Apply topsoil and seed where needed
- Add netting and straw, to keep seed in place.
